# Diabo Verde FTW

Landing page promocional para o termogênico "Diabo Verde FTW".

## Descrição

Este projeto é uma página estática em HTML que apresenta um produto de suplementos esportivos com foco em queima de gordura e aumento de energia para treinos.

## Tecnologias usadas

- HTML5
- Tailwind CSS via CDN
- Lucide Icons via CDN
- JavaScript simples para configuração dinâmica dos textos e links

## Recursos

- Design responsivo construído com Tailwind CSS
- Seções de benefícios, uso recomendado e depoimentos
- Botões de CTA para redirecionamento a um link de afiliado
- Aparência escura com destaque verde neon

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Edite o arquivo para alterar textos, imagens ou links de afiliado.
3. O projeto não precisa de compilação; é uma página estática.

## Estrutura do projeto

- `index.html` - página principal do site.
- `README.md` - documentação do projeto.

## Observações

- O link de afiliado usado no projeto aponta para uma página de compra na Shopee.
- Certifique-se de atualizar o conteúdo e os links antes de publicar em produção.
